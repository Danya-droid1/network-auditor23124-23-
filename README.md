ОПИСАНИЕ

================================================================================



Network Auditor автоматизирует процесс мониторинга сетевой безопасности в образовательных организациях. Система позволяет проводить регулярный аудит открытых сетевых портов, выявлять уязвимые сетевые службы и формировать регламентированную отчётность для специалистов по информационной безопасности.



Проект разработан в рамках преддипломной практики и выпускной квалификационной работы.



================================================================================

ВОЗМОЖНОСТИ

================================================================================



\- TCP-сканирование портов — проверка открытых портов на целевых хостах.

\- Сопоставление с базой уязвимостей — автоматическое определение уровня риска для обнаруженных сервисов.

\- Реестр сетевых активов — учёт серверов, рабочих станций и другого оборудования.

\- Генерация отчётов — экспорт результатов в форматы DOCX и XLSX.

\- Разграничение прав доступа — три роли пользователей (администратор, аналитик, аудитор).

\- Журналирование действий — запись всех значимых событий в audit log.

\- Управление базой уязвимостей — CRUD-операции для справочника известных угроз.

\- Настраиваемое сканирование — выбор диапазонов IP, портов и таймаутов.

\- Цветовая индикация рисков — визуальное выделение критических уязвимостей.

УСТАНОВКА И ЗАПУСК

================================================================================



1\. Клонирование репозитория



git clone https://github.com/Danya-droid1/network-auditor23124-23-.git

cd network-auditor23124-23-



2\. Создание виртуального окружения



python -m venv venv

venv\\Scripts\\activate



3\. Установка зависимостей



pip install -r requirements.txt



4\. Установка и настройка PostgreSQL



1\) Установите PostgreSQL 14+ с официального сайта: https://www.postgresql.org/

2\) Создайте базу данных, выполнив SQL-скрипт:



psql -U postgres -f database/init.sql



5\. Настройка подключения к БД



Откройте файл src/core/database\_manager.py и укажите параметры подключения:



db\_url = "postgresql://postgres:ваш\_пароль@localhost:5432/network\_auditor"



6\. Запуск приложения



python main.py

СТРУКТУРА БАЗЫ ДАННЫХ

================================================================================



База данных PostgreSQL содержит 10 таблиц:



Таблица               Описание

\--------------------------------------------------------------------------------

roles                 Роли пользователей (admin, analyst, auditor)

users                 Учётные записи пользователей

network\_segments      Сегменты сети (административный, учебный, филиалы, гостевой)

assets                Сетевые активы (серверы, рабочие станции)

vulnerability\_db      База известных уязвимостей с привязкой к CVE

scan\_tasks            Задачи сканирования

scan\_results          Результаты сканирования (открытые порты)

reports               История сгенерированных отчётов

audit\_logs            Журнал действий пользователей

system\_settings       Настройки системы
